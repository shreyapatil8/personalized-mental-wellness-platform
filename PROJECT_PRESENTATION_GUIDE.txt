========================================
PROJECT PRESENTATION GUIDE
========================================
Inspected: 29 September 2026. No application code or database records changed.

1. PROJECT IN SIMPLE WORDS

Wellspace helps college students reflect on their daily well-being.
Students can record moods, write journals, and see their wellness history.
They can use a wellness assistant and request counselling appointments.
The purpose is personal reflection and support, not medical diagnosis.

2. HOW TO RUN THE PROJECT

These instructions use Windows PowerShell.

Step 1: Open PowerShell in the project folder:
cd "D:\Personalized_Mental_Wellness_Platform\Personalized_Mental_Wellness_Platform"
On another computer, use the folder where you copied the project.

Step 2: Check prerequisites.
You need Node.js 20+, pnpm, MongoDB, and Python 3.13 for the stress model.
This computer already has Node 22, Python, and a running MongoDB service.

Step 3: For a fresh setup, run:
pnpm install --store-dir .pnpm-store
pnpm setup:local
Skip this step when using the already prepared, running project.

Step 4: Check backend/.env. The current database address is:
MONGODB_URI=mongodb://127.0.0.1:27017/wellness_research
MongoDB must be running. On this computer, its Windows service is MongoDB.
Use Windows Services to start it if stopped.
The backend connects to MongoDB before it starts accepting requests.
Copying the project folder does NOT copy the MongoDB accounts or records.
On another computer, install/start MongoDB and configure its address first.

Step 5: On a new computer, prepare Python for the saved model:
python -m venv ml/.venv
& ml/.venv/Scripts/python.exe -m pip install -r ml/requirements-lock.txt
Use Python 3.13. Do not rely on a virtual environment copied from another PC.
Skip this step on this prepared computer. Keep ml/models with the project.
No separate Python server or model retraining is needed.

Step 6: Start both application parts from the project folder:
pnpm dev
Keep the terminal open. To run them separately instead:
Terminal 1: pnpm dev:backend
Terminal 2: pnpm dev:frontend
Both terminals must start in the project folder.
At inspection, both were already running. Do not start duplicate servers.

Step 7: Open http://localhost:5173
Backend check: http://localhost:5000/api/health should show status "ok".
Use localhost consistently. Keep the frontend on port 5173.
pnpm start starts ONLY the backend; it does not start the website.

Step 8: Register a student or use an existing account below, then log in.
Rehearse the complete flow on the presentation computer today.

9. IMPORTANT THINGS TO REMEMBER

- frontend: React/Vite/Tailwind screens. backend: Node.js/Express APIs.
- MongoDB stores accounts, assessments, tracking, chat and appointments.
- ml: Python/scikit-learn; the saved model is logistic regression.
- shared: question definitions. docs/research: explanations and test results.
- Roles: student, counsellor, admin. Counsellors need activation.
- Remember three different forms: initial 15, WHO-5 5, stress survey 22.
- Journal sentiment is selected by the user, not automatically detected.
- Counsellor summaries need profile consent AND appointment sharing.
- This is a research prototype, not a diagnosis, therapy or emergency service.
- Keep terminals open. Sign out through Menu when changing accounts.
